# Thème web musical — Paheko

Accueil et contact reliés à la configuration du module Espace musical ; pages et thème Paheko conservés.

## Installation

Ce dépôt contient une variante du module Paheko `web`, dans `modules/web/`. Gardez cette variante dans un dépôt séparé des autres thèmes `web`. Utilisez le dossier avec la procédure d’installation des modules personnalisés correspondant à votre instance Paheko.

Vérifiez la compatibilité avec la version de Paheko utilisée avant le déploiement.
